# leak-detect-web

Website for Anton's **third business**: a **swimming pool leak detection** company,
run separately from All About Pools and Simplicrete.

Repo and vault folder are named by function (`leak-detect-web`, `07 - Leak
Detection`) - **brand-neutral**, so nothing needs renaming once Anton picks a name.
Only the site's visible copy carries a name.

## What the business does

Non-destructive pool leak detection: pressure testing plumbing lines, acoustic
location, dye testing the shell/fittings, dive inspection. Locates the leak
precisely and hands over a written report - *before* anyone breaks concrete.
(Research pulled from asppoolco.com, fluidra.com, pooltech.com, reyesleakdetection.com.)
